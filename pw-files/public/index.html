正式用例 · 可保存、可反复跑
  • 推荐流程：生成草稿 → 编辑保存 → 运行 → 样式守护
  • 已有 YAML 可跳过探索，直接选文件 / 编辑后运行
  • 想先验证「能不能跑通」请用上方 Tab「口语试跑」；本页是长期维护的用例沉淀
1. 生成草稿（可选）

路径不熟时用 Explore：ego 代操探索 → 语义轨迹 → 填入下方编辑器（只出草稿，不判定通过/失败）。已有用例可跳过。

2. 编辑并保存
确认草稿无误后保存到 tests/definitions/
3. 运行用例
读取上方 YAML → 按语义步骤执行（playwright 或 ego）。有自愈时结果区可「应用自愈建议」（不改 assert）。
4. 样式守护

用例稳定后：用上方同一 Intent → pw 截图 + computed style 指纹 → Golden 对比。

运行 YAML 用例 → 截图对比 → 报告三档分类

5. 页面变化检测

分区语义哈希 + 结构/文本分级：intent 截图 → compare → 可选晋升 Golden。

运行 → 结构/文本哈希对比 → 内容更新 vs 界面变更分级

快速验证 · 用一句话试流程
  • 用自然语言描述步骤并立刻执行，看能不能跑通（默认 ego；可选 Playwright）
  • 与 YAML Tab 的 Explore 不同：这里会判定通过/失败；Explore 只探索出草稿、不验通过
  • 试跑通过后点「转为 YAML 用例」，再到 YAML Tab 编辑保存 → 运行 → 样式守护
  • 试跑完成后可点「复制试跑反馈」，把流程数据贴给 AI 排查
