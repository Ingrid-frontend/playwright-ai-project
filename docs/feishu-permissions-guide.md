# 飞书开放平台应用权限（速查）

目标：为“创建飞书文档 + 上传图片/附件”配置最小必要权限。

## 必需权限列表（最小集合）

### 1. 文档权限

| 权限名称 | 权限代码 | 用途 | 必需性 |
|---------|----------|------|--------|
| 获取与创建云文档 | `docx:document` | 创建飞书文档 | ✅ 必需 |
| 获取与编辑云文档 | `docx:document` | 编辑飞书文档内容 | ✅ 必需 |
| 只读获取云文档 | `docx:document:readonly` | 读取飞书文档 | ✅ 必需 |

### 2. 云文档权限

| 权限名称 | 权限代码 | 用途 | 必需性 |
|---------|----------|------|--------|
| 获取与上传云空间文件 | `drive:drive` | 上传图片到飞书 | ✅ 必需 |
| 只读获取云空间文件 | `drive:drive:readonly` | 读取云空间文件 | ✅ 必需 |
| 获取与编辑云空间文件 | `drive:file` | 管理文件 | ✅ 必需 |

### 3. 权限管理权限

| 权限名称 | 权限代码 | 用途 | 必需性 |
|---------|----------|------|--------|
| 获取与编辑云空间权限 | `drive:permission` | 分享文档和管理权限 | ✅ 必需 |

## 配置步骤（简版）

1. 在飞书开放平台创建应用
2. 在「权限管理」里勾选上表权限
3. 发布/启用应用，并按平台要求完成可用范围配置（企业内/特定人员）

### Q3: 权限范围如何选择？

**A**: 权限范围说明：

- **全部用户**：应用可以访问所有用户的资源
  - 适用于：企业内部工具
  - 安全性：较低

- **指定用户**：应用只能访问指定用户的资源
  - 适用于：个人工具
  - 安全性：较高

- **仅自己**：应用只能访问创建者的资源
  - 适用于：个人开发测试
  - 安全性：最高

**推荐**：个人开发选择"仅自己"，企业内部工具选择"全部用户"

### Q4: 权限审核需要多长时间？

**A**: 审核时间说明：

- **个人应用**：通常立即开通，无需审核
- **企业应用**：需要管理员审核，通常 1-3 个工作日
- **特殊权限**：需要飞书官方审核，可能需要更长时间

### Q5: 如何撤销权限？

**A**: 撤销权限步骤：

1. 进入应用详情页
2. 点击左侧菜单"权限管理"
3. 找到要撤销的权限
4. 点击"撤销"按钮
5. 确认撤销操作

**注意**：撤销权限后，相关功能将无法使用

### Q6: 权限过期了怎么办？

**A**: 权限不会过期，但访问令牌会过期：

1. **访问令牌有效期**：2 小时
2. **刷新令牌**：脚本会自动刷新
3. **无需手动处理**：脚本会自动管理令牌

### Q7: 权限不足错误如何排查？

**A**: 排查步骤：

1. **查看错误信息**：
   ```bash
   npm run create-feishu-doc
   ```
   查看具体的错误信息

2. **检查权限列表**：
   - 进入飞书开放平台
   - 查看已开通的权限
   - 确认所需权限已开通

3. **检查应用状态**：
   - 确认应用已启用
   - 确认应用未被封禁

4. **联系飞书技术支持**：
   - 如果以上步骤都无法解决问题
   - 联系飞书技术支持寻求帮助

### Q8: 可以申请更多权限吗？

**A**: 可以申请更多权限：

1. **评估需求**：
   - 确定需要哪些额外权限
   - 评估权限的必要性

2. **提交申请**：
   - 进入"权限管理"
   - 搜索所需权限
   - 提交申请

3. **等待审核**：
   - 等待管理员审核
   - 审核通过后即可使用

**注意**：只申请必要的权限，避免权限过大
