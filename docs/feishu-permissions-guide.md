## 📖 权限详细说明

### 1. 文档权限 (`docx:document`)

**权限代码**：`docx:document`

**功能**：
- ✅ 创建新的飞书文档
- ✅ 编辑文档内容
- ✅ 添加文本、图片等内容块
- ✅ 设置文档格式

**API 使用**：
- `POST /open-apis/docx/v1/documents` - 创建文档
- `POST /open-apis/docx/v1/documents/{document_id}/blocks/batch_create` - 添加内容块

**权限范围**：
- 用户授权的文档
- 应用创建的文档

**安全级别**：中

---

### 2. 云文档权限 (`drive:drive`)

**权限代码**：`drive:drive`

**功能**：
- ✅ 上传文件到云空间
- ✅ 管理云空间文件
- ✅ 创建文件夹
- ✅ 删除文件

**API 使用**：
- `POST /open-apis/drive/v1/medias/upload_all` - 上传图片

**权限范围**：
- 用户授权的云空间
- 应用创建的文件夹

**安全级别**：中

---

### 3. 权限管理权限 (`drive:permission`)

**权限代码**：`drive:permission`

**功能**：
- ✅ 分享文档
- ✅ 设置文档访问权限
- ✅ 管理文档分享链接
- ✅ 设置分享链接的有效期

**API 使用**：
- `POST /open-apis/drive/v1/permissions/{file_token}/share` - 分享文档

**权限范围**：
- 应用创建的文档
- 用户授权的文档

**安全级别**：高

## ⚙️ 配置步骤

### 步骤 1：登录飞书开放平台

1. 访问飞书开放平台：https://open.feishu.cn/
2. 使用飞书账号登录
3. 进入"管理后台"

### 步骤 2：创建应用

1. 点击"创建应用"
2. 选择应用类型：
   - **企业自建应用**：适合企业内部使用
   - **个人应用**：适合个人开发者
3. 填写应用信息：
   - 应用名称：`Playwright AI 测试工具`
   - 应用描述：`自动化测试结果报告生成工具`
   - 应用图标：上传应用图标（可选）
4. 点击"创建"

### 步骤 3：获取凭证

1. 进入应用详情页
2. 点击左侧菜单"凭证与基础信息"
3. 复制以下信息：
   - **App ID**：应用的唯一标识
   - **App Secret**：应用的密钥（点击"查看"按钮）
4. 保存到安全的地方

### 步骤 4：配置权限

1. 点击左侧菜单"权限管理"
2. 搜索并开通以下权限：

#### 4.1 开通文档权限

搜索 `docx`，找到以下权限并开通：

- ✅ **获取与创建云文档** (`docx:document`)
  - 点击"申请权限"
  - 选择"申请范围"：全部用户
  - 填写"申请理由"：用于创建自动化测试报告文档
  - 点击"提交"

- ✅ **只读获取云文档** (`docx:document:readonly`)
  - 点击"申请权限"
  - 选择"申请范围"：全部用户
  - 填写"申请理由"：用于读取测试报告文档
  - 点击"提交"

#### 4.2 开通云文档权限

搜索 `drive`，找到以下权限并开通：

- ✅ **获取与上传云空间文件** (`drive:drive`)
  - 点击"申请权限"
  - 选择"申请范围"：全部用户
  - 填写"申请理由"：用于上传测试截图
  - 点击"提交"

- ✅ **只读获取云空间文件** (`drive:drive:readonly`)
  - 点击"申请权限"
  - 选择"申请范围"：全部用户
  - 填写"申请理由"：用于读取测试截图
  - 点击"提交"

#### 4.3 开通权限管理权限

搜索 `permission`，找到以下权限并开通：

- ✅ **获取与编辑云空间权限** (`drive:permission`)
  - 点击"申请权限"
  - 选择"申请范围"：全部用户
  - 填写"申请理由"：用于分享测试报告文档
  - 点击"提交"

### 步骤 5：审核权限

1. 提交权限申请后，等待管理员审核
2. 审核通过后，权限状态会变为"已开通"
3. 如果是个人应用，权限会自动开通

### 步骤 6：配置环境变量

1. 创建 `.env` 文件：
   ```bash
   echo "FEISHU_APP_ID=your_app_id" > .env
   echo "FEISHU_APP_SECRET=your_app_secret" >> .env
   ```

2. 或者创建 `feishu-config.json` 文件：
   ```json
   {
     "appId": "your_app_id",
     "appSecret": "your_app_secret"
   }
   ```

### 步骤 7：测试权限

1. 运行测试脚本：
   ```bash
   npm run create-feishu-doc
   ```

2. 查看输出结果：
   - 如果成功，会显示文档链接
   - 如果失败，会显示错误信息

## ❓ 常见问题

### Q1: 权限申请被拒绝了怎么办？

**A**: 如果权限申请被拒绝，可以：

1. **检查申请理由**：
   - 确保申请理由清晰明确
   - 说明使用场景和目的

2. **联系管理员**：
   - 如果是企业应用，联系企业管理员
   - 说明使用场景和必要性

3. **重新申请**：
   - 根据拒绝原因修改申请理由
   - 提供更详细的使用说明

### Q2: 权限开通后仍然无法使用怎么办？

**A**: 检查以下几点：

1. **检查 App ID 和 App Secret**：
   ```bash
   cat .env | grep FEISHU
   ```

2. **检查权限状态**：
   - 进入飞书开放平台
   - 查看权限是否已开通
   - 确认权限状态为"已开通"

3. **检查应用状态**：
   - 确认应用已启用
   - 确认应用未被封禁

4. **重新测试**：
   ```bash
   npm run create-feishu-doc
   ```

### Q3: 权限范围如何选择？

**A**: 权限范围说明：

- **全部用户**：应用可以访问所有用户的资源
  - 适用于：企业内部工具
  - 安全性：较低

- **指定用户**：应用只能访问指定用户的资源
  - 适用于：个人工具
  - 安全性：较高

- **仅自己**：应用只能访问创建者的资源
  - 适用于：个人开发测试
  - 安全性：最高

**推荐**：个人开发选择"仅自己"，企业内部工具选择"全部用户"

### Q4: 权限审核需要多长时间？

**A**: 审核时间说明：

- **个人应用**：通常立即开通，无需审核
- **企业应用**：需要管理员审核，通常 1-3 个工作日
- **特殊权限**：需要飞书官方审核，可能需要更长时间

### Q5: 如何撤销权限？

**A**: 撤销权限步骤：

1. 进入应用详情页
2. 点击左侧菜单"权限管理"
3. 找到要撤销的权限
4. 点击"撤销"按钮
5. 确认撤销操作

**注意**：撤销权限后，相关功能将无法使用

### Q6: 权限过期了怎么办？

**A**: 权限不会过期，但访问令牌会过期：

1. **访问令牌有效期**：2 小时
2. **刷新令牌**：脚本会自动刷新
3. **无需手动处理**：脚本会自动管理令牌

### Q7: 权限不足错误如何排查？

**A**: 排查步骤：

1. **查看错误信息**：
   ```bash
   npm run create-feishu-doc
   ```
   查看具体的错误信息

2. **检查权限列表**：
   - 进入飞书开放平台
   - 查看已开通的权限
   - 确认所需权限已开通

3. **检查应用状态**：
   - 确认应用已启用
   - 确认应用未被封禁

4. **联系飞书技术支持**：
   - 如果以上步骤都无法解决问题
   - 联系飞书技术支持寻求帮助

### Q8: 可以申请更多权限吗？

**A**: 可以申请更多权限：

1. **评估需求**：
   - 确定需要哪些额外权限
   - 评估权限的必要性

2. **提交申请**：
   - 进入"权限管理"
   - 搜索所需权限
   - 提交申请

3. **等待审核**：
   - 等待管理员审核
   - 审核通过后即可使用

**注意**：只申请必要的权限，避免权限过大
