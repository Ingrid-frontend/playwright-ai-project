## 报告信息契约

1. **摘要**：环境、模块、时间、视口、角色、版本、基线身份。未知信息明确写未知。
2. **检查范围**：实际捕获的状态与计划状态分开；执行完成、截图存在不等于视觉验收通过。
3. **复核卡片**：位置、观察事实、待确认假设、图片、下一步与建议责任方。技术信号聚合为证据，不机械累加成缺陷数。
4. **状态**：页面变化待复核 / 检查有效性待核对 / 人工确认缺陷 / 人工确认正常变化 / 未覆盖。本样例没有人工确认的产品缺陷。
5. **来源**：区分采集事实、自动规则、模型推断、人工结论。本次分析为助手对既有产物的静态走读，非测试或前端签收。
6. **边界**：无法比较、审计不可用、缺少版本或基线依据均不得伪装为正常通过；不以缺陷总数代替发布判断。
